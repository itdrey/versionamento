O que é versionamento?entenda

Versionamento é um sistema que registra todas as alterações feitas em arquivos ao longo do tempo, permitindo que você recupere versões específicas quando necessário. O Git é a ferramenta local, e o GitHub é a plataforma online que hospeda esses repositórios.

📸

Histórico completo

Cada alteração é registrada como um snapshot do projeto, com autor, data e mensagem descritiva.

🔁

Reversão segura

Se algo der errado, você pode voltar a qualquer versão anterior com um único comando.

🤝

Colaboração

Múltiplas pessoas podem trabalhar no mesmo projeto simultaneamente sem conflitos caóticos.

ramificações

Branches

Uma branch é uma ramificação independente do código. Você pode criar uma branch para desenvolver uma nova feature sem afetar o código principal.

main — branch principal, código em produção
feature/login — nova funcionalidade isolada
hotfix/bug — correção urgente de bug
referência rápida

Pull Request

Um Pull Request (PR) é uma proposta de integração de código. Você pede que suas alterações sejam revisadas e incorporadas à branch principal.

01

Fork ou Branch

Crie uma cópia do repositório (fork) ou uma nova branch para suas alterações.

Commits

Abrir PR

No GitHub, abra um Pull Request descrevendo o que foi feito e por quê.
